오늘도 퇴근 개인정보처리방침

최종 수정일: 2026년 9월 26일 (1.0.4 업데이트 설정 반영)

이 앱은 개인정보를 수집하지 않습니다. 입력한 내용은 사용자의 PC에만 저장됩니다. 인터넷은 새 버전이 있는지 Microsoft Store에 확인할 때만 씁니다.

수집하는 정보

없습니다. 이 앱은 이름·연락처·위치·사용 기록을 포함해 어떤 개인정보도 수집하거나 전송하지 않습니다. 광고와 사용 분석 도구를 넣지 않았습니다.

앱이 저장하는 것

사용자가 직접 입력한 다음 내용이 사용자의 PC에만 저장됩니다.

  • 근무 요일과 출퇴근·점심 시간
  • 월급과 월급날 (입력하지 않아도 앱을 쓸 수 있습니다)
  • 일정, 할 일, 디데이, 휴가, 점심 메뉴
  • 화면 설정 (스킨, 테마, 위젯 구성, 창 위치와 크기)

저장 위치는 %LOCALAPPDATA%\Packages\dang0321.59011A50997D_...\LocalState\settings.json 입니다. 이 파일은 사용자의 PC를 벗어나지 않습니다.

인터넷 연결

1.0.3 버전부터 자동 업데이트를 위해 Windows의 Microsoft Store 기능으로 새 버전이 있는지 확인하고, 있으면 Microsoft Store에서 받습니다. 1.0.4 버전부터 "알림만"을 고르면 확인만 하고, 사용자가 알림을 누를 때 받습니다. 이 확인은 Windows와 Microsoft Store 사이에서 이루어지며 Microsoft의 개인정보처리방침을 따릅니다. 앱에 입력한 내용은 보내지 않습니다.

설정 → 일반 → 업데이트를 "끄기"로 두거나(1.0.3은 자동 업데이트를 끄거나) [회사 PC에 맞추기]를 누르면 확인하지 않습니다. 1.0.3에서 꺼 두었다면 1.0.4에서도 꺼진 채로 둡니다. 그 밖에 서버로 보내는 정보나 통계 전송은 없습니다. 공휴일 정보는 앱 안에 들어 있습니다.

제3자 제공

수집하는 정보가 없으므로 제3자에게 제공하거나 판매하는 정보도 없습니다.

오류 기록

앱에 문제가 생기면 오류 내용이 사용자의 PC 안(위 저장 위치의 logs 폴더)에만 기록되고 14일 뒤 지워집니다. 이 기록은 자동으로 전송되지 않습니다.

결제

앱 안에서 프로 기능을 구매하면 결제는 Microsoft Store가 처리합니다. 결제 정보는 Microsoft가 다루며 앱은 구매 여부만 확인합니다. 카드번호 같은 결제 정보는 앱이 받지도, 저장하지도 않습니다.

데이터 삭제

Windows 설정 → 앱에서 이 앱을 제거하면 위에 적은 저장 파일도 함께 지워집니다. 앱 안의 설정 → 데이터에서 직접 내보내거나 지울 수도 있습니다.

어린이

이 앱은 어린이를 대상으로 하지 않으며, 나이와 관계없이 어떤 개인정보도 수집하지 않습니다.

Privacy Policy (English)

Last updated: September 23, 2026 (auto update in 1.0.3)

This app does not collect any personal information. Everything you enter is stored only on your own PC. The network is used only to check the Microsoft Store for new versions of the app.

Information we collect

None. The app does not collect, transmit, or share any personal data. It contains no advertising and no analytics.

What the app stores

Your working hours, salary and payday (both optional), schedules, to-dos, D-days, days off, lunch menus, and display settings are saved in a single settings file inside your own user profile. The file never leaves your PC.

Network use

Starting with version 1.0.3, the app uses the Windows Microsoft Store API to check for and install new versions of itself. This check happens between Windows and the Microsoft Store and is covered by Microsoft's privacy statement. Nothing you enter in the app is sent. You can turn it off in Settings → General → Auto update (it is also turned off by "Set up for a work PC"). The app sends no other data and no analytics. Korean public holiday data is bundled with the app.

Third parties

No data is collected, so no data is shared with or sold to third parties.

Error logs

If an error occurs, details are written to a local log folder on your PC and deleted after 14 days. Logs are never transmitted.

Purchases

In-app purchases are processed by the Microsoft Store. The app only checks whether the purchase was made and never receives or stores payment details.

Deleting your data

Uninstalling the app from Windows Settings removes the stored file as well.

Children

The app is not directed to children and collects no personal information from anyone.

Changes

Any changes to this policy will be posted on this page with the date.
