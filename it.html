네트워크

1.0.3부터 자동 업데이트가 있습니다. Windows의 스토어 기능(Windows.Services.Store의 StoreContext)으로 6시간마다 새 버전이 있는지 묻고, 있으면 Microsoft Store에서 받아 위젯을 쓰지 않을 때 설치합니다. 연결은 Windows가 Microsoft Store와 하고, 앱이 직접 여는 연결은 없습니다. 입력한 내용은 보내지 않습니다.

  • 끄는 방법: 설정 → 일반 → 자동 업데이트, 또는 "회사 PC에 맞추기". 끄면 업데이트를 확인하지 않습니다.
  • 끄더라도 Microsoft Store 자체의 앱 자동 업데이트(앱이 꺼져 있을 때 설치)는 Windows·스토어 설정을 따릅니다.

그 밖에 HTTP·소켓 통신 코드는 없습니다. 공휴일 정보도 앱 안에 들어 있어 외부에서 받아오지 않습니다. 따라서 방화벽·프록시 설정이 필요 없고, 사내 정보가 밖으로 나갈 경로가 없습니다.

저장하는 것과 위치

사용자가 넣은 근무 시간, 월급(선택), 일정·할 일·디데이, 휴가, 점심 메뉴, 화면 설정이 JSON 파일 하나에 저장됩니다.

  • 스토어로 설치한 경우: %LOCALAPPDATA%\Packages\<패키지 이름>\LocalState\settings.json
  • 오류 기록: 같은 폴더의 logs (14일 보관, 예외 메시지만 기록)

앱을 제거하면 이 폴더도 함께 지워집니다.

"화면 공유에서 숨기기"에 대해

  • 목적: 회의에서 화면을 공유할 때 위젯에 보이는 월급·수입이 노출되지 않게 하는 기능입니다.
  • 기본은 꺼져 있고, 사용자가 설정에서 직접 켜야 동작합니다. 켜면 위젯 창만 화면 공유·녹화·스크린샷에서 빠집니다. 다른 창이나 화면 전체에는 영향이 없습니다.
  • 사내 모니터링·녹화 정책이 있는 환경에서는 이 기능을 쓰지 않도록 안내하고 있습니다. 앱 설정 화면에도 같은 안내가 적혀 있습니다.
  • 월급을 가리는 다른 방법으로 "금액 숨기기"(설정 → 숨기기, 또는 위젯 오른쪽 클릭 메뉴)가 있습니다. 이 기능은 화면 공유에 영향을 주지 않고, 오늘 번 돈을 금액 대신 퍼센트로만 보여줍니다.

회사 PC에 맞추기

사용자가 한 번에 설정할 수 있는 항목을 앱 안에 두었습니다.

  • 설정 → 숨기기 → 회사 PC에 맞추기 [적용]: 자동 실행 끔, 자동 업데이트 끔, 금액 숨기기 켬, 화면 공유에서 숨기기 끔
  • 처음 켤 때 3단계의 "회사 PC에서 써요": 같은 값으로 시작합니다.

회사에서 배포·안내할 때 이 항목을 알려 주시면, 시작 프로그램 등록, 화면 캡처 제외, 스토어 업데이트 확인을 쓰지 않는 상태로 쓸 수 있습니다.

배포 통제

  • Microsoft Store에서 설치하며, 패키지는 마이크로소프트가 서명합니다.
  • 조직에서 스토어 앱을 통제한다면 위 값으로 허용·차단할 수 있습니다. Intune·AppLocker에서는 보통 패키지 패밀리 이름(PFN) 을 씁니다.
  • 사내 스토어(비즈니스용)나 Intune으로 배포하려면 문의해 주세요.

제거

설정 → 앱 → 설치된 앱에서 제거하면 앱과 저장된 데이터가 함께 지워집니다. 자동 실행 등록도 함께 사라집니다.
